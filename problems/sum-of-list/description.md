## Add a list of numbers ##

## Problem statement
- A given list contains n number of numbers. Your task is to print the summation of the numbers in the given list.

## Input 
A single line of n integers with values v separated by a space 
## Output
An integer depicting summation of the array contents

## Example - (input and output)
7 1 3 2
13

## Constraints
- 1<=n<=100
- -999<=v<=999
